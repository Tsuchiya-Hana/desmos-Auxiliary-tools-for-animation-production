### 基础移动和事件

#### l的使用

在本篇文章里，“线性”指“线性运动”，说白了就是我们小学二年级就学过的匀速运动（即速度不变）。例如隔壁家王奶奶从家出发以114514m/s的恒定速度外出散步，那么给定一个时间，王奶奶运动的路程能直接通过速度乘时间算出来。

如果有一个变量A，要让它从0线性变成1，那么可以直接使用desmos原生的滑块，即在表达式栏里面输入`A=0`，然后再在下面输入`0<=A<=1`，点击左边的播放按钮，A就会从0线性变化为1，我们称这个变化的过程（不一定是要线性）为“移动”或“运动”。

滑块是变量最基本的变化方式（当然还有计时器，这里不说），在desmos中很多地方都要使用到滑块来观察函数图像的变化过程。如果让滑块A在从0线性变化为1的同时，让变量B从3线性变化成5呢？

这里引入一个新的函数`lerp`，在该项目中简写为l，其参数为`l(a,b,t)`，其中a是开始值，b时结束值，t是一个`0～1`之间的实数。可以想象成王奶奶0分钟时从邮局（离家a米）的地方出发，1分钟时到达火星（离家b米）（这里假设王奶奶是一维生物，火星、邮局和王奶奶家在同一直线上，无论正负或谁更远谁更近），求当王奶奶第t分钟时离家多少米。则上面说的变量B可以写成`B=l(3,5,A)`。

好的，在理想情况下王奶奶可以在`0～1`分钟内从邮局匀速走到火星，但是更多时候不是`0～1`分钟，可能出发晚到的晚（如`5～2233`分钟），也有可能出发晚但到得更早（如`0.22～0.33`分钟），这时该怎么办呢？

#### m的使用

这里再引入一个新的函数m，其参数为`m(t1,a1,t2,a2,t,s)`，其中t1是王奶奶从邮局出发的时间，t2是王奶奶到达火星的时间，a1是邮局到王奶奶家的距离，a2是火星和王奶奶家的距离，t则是现在的时间，s是缓动（默认值为1，1是我们现在探讨的最简单的运动，即匀速运动，这个先不用管，后面会讲）。例如王奶奶家离邮局3米，离火星5米，从第0.22分钟在邮局出发，速度恒定，然后在第0.33分钟到达火星，现在是第A分钟，求王奶奶离家的距离C，那么`C=m(0.22,3,0.33,5,t,1)`。

我们称这样的`[t1,a1,t2,a2,s]`为一个**事件**，可以理解为王奶奶的一次行程，例如上面列举的`[0.22,3,0.33,5,1]`。

> [!TIP]
> s为一个1～29之间的整数（包括1和29）

#### 通道

自从又了缓动，王奶奶变得更有活力了，为了庆祝一下这个非常有纪念意义的时刻，王奶奶规划了一下今天的行程：
|事件编号|行程开始时间（第几分钟）|行程起点和王奶奶家的距离|行程结束时间（第几分钟）|行程终点和王奶奶家的距离|缓动|
|-|-|-|-|-|-|
|**1**|2|3（邮局）|5|114（火星）|1|
|**2**|7|114（火星）|10|514（桃花源）|2|
|**3**|12|514（桃花源）|15|78（某火星翼族的家）|2|
|**4**|18|78（某火星翼族的家）|23|91（某张放在下界的床）|3|

不难发现，王奶奶今天的行程由4个事件组成，分别为`[2,3,5,114,1],[7,114,10,514,2],[12,514,15,78,2],[18,78,23,91,3]`，如何将这四个事件统筹起来呢？

这里引入一个新的函数`m_2`，参数为`m_2(l,t)`，其中l是一个列表，可以装下多个事件。5个5个数字一组，每5个数字代表一个事件。如果说给定一个时间t，问在t分钟的时候王奶奶离家的距离D是多远，那么
`D=m_2([2,3,5,114,1,7,114,10,514,2,12,514,15,78,2,18,78,23,91,3],t)`
最终的D是一个数字值。
我们称这种由一个两个或很多个**时间上互不重叠，且时间值递增**的事件组成，最后只反映**一个人**在某个时间离家的距离的数组，称为**一个通道**
> [!IMPORTANT]
> 同一通道内的事件的时间不能重叠，如`[2,3,5,114,1, 3,114,4,514,2]`就不是一个合格的通道
> 同一通道内的事件的时间要递增，如`[3,3,2,114,1, 0.5,114,5,514,3]`就不是一个合格的通道
