### 基础移动和事件

在本篇文章里，“线性”指“线性运动”，说白了就是我们小学二年级就学过的匀速运动（即速度不变）。例如隔壁家王奶奶从家出发以114514m/s的恒定速度外出散步，那么给定一个时间，王奶奶运动的路程能直接通过速度乘时间算出来。

如果有一个变量A，要让它冲0线性变成1，那么可以直接使用desmos原生的滑块，即在表达式栏里面输入`A=0`，然后再在下面输入`0<=A<=1`，点击左边的播放按钮，A就会从0线性变化为1，我们称这个变化的过程（不一定是要线性）为“移动”或“运动”。

滑块是变量最基本的变化方式（当然还有计时器，这里不说），在desmos中很多地方都要使用到滑块来观察函数图像的变化过程。如果让滑块A在从0线性变化为1的同时，让变量B从3线性变化成5呢？

这里引入一个新的函数`lerp`，在该项目中简写为l，其参数为`l(a,b,t)`，其中a是开始值，b时结束值，t是一个0～1之间的实数。可以想象成王奶奶0分钟时从邮局（离家a米）的地方出发，1分钟时到达火星（离家b米）（这里假设王奶奶是一维生物，火星、邮局和王奶奶家在同一直线上，无论正负或谁更远谁更近），求当王奶奶第t分钟时离家多少米。则上面说的变量B可以写成`B=l(3,5,A)`

好的，在理想情况下王奶奶可以在0～1分钟内从邮局匀速走到火星，但是更多时候不是0～1分钟，可能出发晚到的晚（如5～2233分钟），也有可能出发晚但到得更早（如0.22～0.33分钟），这时该怎么办呢？

这里再引入一个新的函数m，其参数为`m(t1,a1,t2,a2,t,s)`，其中t1是王奶奶从邮局出发的时间，t2是王奶奶到达火星的时间，a1是邮局到王奶奶家的距离，a2是火星和王奶奶家的距离，t则是现在的时间，s是缓动（默认值为1，1是我们现在探讨的最简单的运动，即匀速运动，这个先不用管，后面会讲）。例如王奶奶家离邮局3米，离火星5米，从第0.22分钟在邮局出发，速度恒定，然后在第0.33分钟到达火星，现在是第A分钟，求王奶奶离家的距离C，那么`C=m(0.22,3,0.33,5,t,1)`
