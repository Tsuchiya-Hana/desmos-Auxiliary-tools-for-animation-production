### ✨ 库功能概述
这套自定义函数库内置大量工具函数：
- 几何绘制：任意阶贝塞尔曲线、分段三次贝塞尔、极坐标变换、参数圆等
- 粒子系统：区域随机粒子生成、循环边界粒子运动
- 数值工具：数值限幅、区间归一化、循环回卷、线性插值
- 随机工具：种子可控随机列表、序列生成
- 列表工具：列表插入、删除、替换、下标查找
- 动画缓动：内置30+缓动函数，支持单段/多段串联动画
- 高级工具：矩阵重塑、列表映射模板

### 🎯 适合人群
- 使用 Desmos 制作数学动画、参数图形的创作者
- 想快速实现粒子、贝塞尔、缓动动画，不想重复手写底层表达式的用户
- 教学演示、视频动画、几何可视化爱好者

### 📌 重要使用须知
1. Desmos 的列表下标**从 1 开始**，不存在下标0，编写表达式时务必注意
2. 本函数库没有内置参数校验，非法参数、列表长度不匹配会直接报错或返回空结果
3. 点列表不能直接传入数值列表函数，需要拆分 `.x` `.y` 坐标单独处理，完成后重新组装点
